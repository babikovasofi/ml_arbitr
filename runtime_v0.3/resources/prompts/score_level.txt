Выбери для каждого критерия одну оценку из списка:
«не раскрыт» — во фрагментах нет ничего по этому критерию;
«слабо раскрыт» — тема затронута общими словами, без конкретики;
«раскрыт частично» — есть по существу, но поверхностно или без обоснования;
«раскрыт в основном» — раскрыт содержательно, с конкретикой;
«раскрыт полностью» — раскрыт исчерпывающе, с цифрами, примерами и обоснованием.

Учитывай только приведённые фрагменты.
Оценивай критерии независимо друг от друга: выступление может хорошо раскрывать один критерий и не раскрывать соседний, поэтому оценки обычно различаются.

Пример: фрагмент "Спасибо за внимание, вопросы?" не раскрывает ничего содержательного.

Верни только JSON-массив из {{ criterion_names | length }} элементов вида {"name": "<название критерия>", "level": "<одна из оценок выше>"} — по одному на каждый критерий в том же порядке, в котором они перечислены выше. Никакого текста кроме массива.
