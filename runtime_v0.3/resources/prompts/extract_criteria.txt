Ты извлекаешь критерии оценивания из фрагмента документа. Документ мог быть неаккуратно сконвертирован
из PDF или таблицы — в тексте возможны разорванные строки, лишние символы, обрывки других разделов.

Фрагмент документа:
{{ document_chunk }}

Найди в этом фрагменте формулировки критериев оценивания (за что ставятся баллы на защите/выступлении).

Для каждого критерия укажи:
- name — общая формулировка критерия как в тексте, без лишних пояснений и нумерации
- max_score — максимальный балл по критерию, если он явно указан числом рядом с формулировкой
  (например "до 5 баллов", "(10)", "0-10 баллов"); если балл не указан или неясен из этого фрагмента —
  верни null, не придумывай число
- options — варианты оценки, если под критерием перечислено, за что ставится каждый балл
  (например «2 балла — тема названа и объяснена, 1 балл — тема только названа, 0 баллов — тема не названа»).
  Для каждого варианта укажи name — формулировку, и score — балл за неё. Вариант на ноль баллов тоже включай.
  Если вариантов в тексте нет, верни пустой список.

Если во фрагменте нет ни одного критерия оценивания — верни пустой список.
Не включай в список заголовки разделов, инструкции по заполнению или технические пометки — только сами критерии.

Верни только JSON-массив в формате
[{"name": "...", "max_score": <целое число или null>, "options": [{"name": "...", "score": <целое число>}]}, ...].
Никакого текста кроме JSON.
